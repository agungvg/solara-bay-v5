Solara Bay is a complete open-world crime game that plays offline in a desktop browser: a sun-soaked beachfront city to explore on foot and by car, traffic and pedestrians, cars to steal, a wanted system with SBP police response and checkpoint roadblocks, 8 staged story missions, combat, a dense HUD with a real-street minimap, and a save.

## Run it

```sh
python3 -m http.server 8130 --directory game
```

Then open http://localhost:8130 in a desktop browser. Drive with W A S D, get out with E, shoot with the mouse, work the crew with Z X C, and press M for the next job.
